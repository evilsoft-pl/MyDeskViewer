# MyDeskViewer

MyDeskViewer is a fast and lightweight remote desktop and remote support solution for Windows, Android, macOS, Linux and FreeBSD.

It is designed as an alternative to remote access tools such as TeamViewer and AnyDesk, with a focus on simplicity, performance and cross-platform support.

## Download

Official downloads are available at:

https://mydeskviewer.com

## Supported platforms

- Windows
- Android
- macOS
- Linux
- FreeBSD

## Bug reports

Found a bug?

Please open an Issue and include:

- MyDeskViewer version
- Operating system
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Relevant logs or screenshots

Please do not include passwords, access credentials, private keys or other sensitive information.
